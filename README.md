# Kate Mel — Product Designer Portfolio

React/Vite portfolio based on the supplied project, populated with Kate Mel's content and locally stored artwork.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:3000`). Do not open the source `index.html` directly: it contains TypeScript modules that are compiled by Vite.

Production build:

```bash
npm run build
```
